# 2026-07-24 工作日志

## 阅读器右侧文字遮挡修复
- 问题：分页阅读时每页右侧的文字被 `overflow:hidden` 裁切，显示不全
- 原因：列宽计算 `pw = clientWidth - 6` 的右边距不足，亚像素渲染导致右侧文字被裁
- 修复：将 `initPagination()` 和 `goToPage()` 中的 `-6` 改为 `-12`，增大右边距
- 修改文件：`reader/百年孤独-阅读器.html` 第 1199、1245 行

## 手机版阅读区左右留白不均修复
- 问题：手机版右侧留白比左侧多 12px（列宽收窄全部在右侧），用户感知为左侧留白太多、右侧太少
- 修复：给 `.reader-pages` 增加 `padding: 0 6px`，将 12px 空余均分到左右两侧
  - `clientWidth` 包含 padding，`pw = clientWidth - 12` 后列宽刚好等于内容区宽
  - 每页左右各有 6px 等距留白，且不影响右侧防裁切效果
- 修改文件：`reader/百年孤独-阅读器.html` 第 260 行

## 分页留白过大修复
- 问题：`break-inside: avoid-column` 禁止段落跨列分断，长段落在页尾放不下时整段推至下一页，产生大片空白
- 修复：删除 `.chapter-content p` 的 `break-inside: avoid-column`，允许段落自然跨页分断
- 修改文件：`reader/百年孤独-阅读器.html` 第 274 行

## 翻页对齐修复（核心问题）
- 问题：翻页后内容错位跨页。`initPagination()` 用 `pw` 设列宽，`goToPage()` 每次重算 `pw = clientWidth - 12`。`clientWidth` 波动导致 `translateX` 与列边界不匹配，翻页越多误差累积越大
- 修复：
  1. 新���全局变量 `SPAN = pw + PAGE_GAP`，在 `initPagination()` 时一次性计算
  2. `goToPage()` 翻页时直接用 `SPAN`，不再重复读 `clientWidth`
  3. `computePageMapping()` 改为用 `SPAN`，居中判定用 `SPAN * 0.5` 替代 `pw / 2`
- 修改位置：第 904、1197-1207、1211-1238、1242-1249 行

## 角色卡片滚动漏透明修复
- 问题：打开角色卡片上下滚动时，内容从圆角处「漏」出，显示透明背景
- 原因：`.char-card` 同时设置 `overflow-y:auto; overflow-x:hidden` 和 `border-radius`，在 Chrome/WebKit 中同轴不同 overflow 值会导致 border-radius 裁剪失效
- 修复：将 `overflow-y:auto; overflow-x:hidden` 合并为 `overflow:auto`
- 修改位置：第 526 行

## 角色卡片滚动穿透主页面修复
- 问题：打开角色卡滚动时，滚到顶部/底部后 scroll 事件穿透到主页面，导致主页面也跟着滚动
- 修复：
  - CSS: `.char-card` 增加 `overscroll-behavior: none`，防止滚动链式传播和弹性回弹
  - JS: `openCharCard()` 打开时锁 body 滚动，`closeCharCard()` 关闭时恢复
- 修改位置：第 527、1471、1484 行
