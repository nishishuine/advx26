# Manifold 流形 — 给 AI 的输出装上语义骨架

**一句话定位：Manifold 是 AI 输出的第三代格式标准——文本还是文本，但每一句话、每一个名词背后，都带着机器可解析的结构化语义。**

## 一、为什么是现在：AI 的"水龙头"没人修

过去三年，整个行业的注意力都在"水管"上——模型能力一路狂飙：GPT-3 到 GPT-4，Claude 3 到 4，DeepSeek 引爆推理模型；输出长度从 2K tokens 涨到 1M tokens。但有一个维度几乎原地踏步：**输出格式**。2019 年 AI 吐纯文字，2026 年的今天，AI 依然在一行接一行地吐 Markdown。

格式决定了消费体验。纯文本时代，用户只能被动阅读；Markdown 给了文本样式，但对机器而言，"何塞是乌尔苏拉的丈夫"依然只是一串字符——AI 自己理解这句话里的关系，它输出的东西却不携带这种理解。HTML 和 Canvas 是第二种尝试：可渲染，但无语义、输出不稳定，每次生成都像抽卡，无法沉淀为标准。

**所有人都在优化模型，没有人在优化格式。Manifold 是第一个认真思考"AI 应该用什么格式跟人类对话"的项目。** 就像笛卡尔用 XYZ 坐标系让几何问题可以被代数计算，Manifold 用内联标注让 AI 输出可以被结构化理解——这正是我们选择的赛道：新坐标，新标准（XYZ）。

## 二、技术范式：内联标注语法

Manifold 的核心是一套极简的标注语法：

```
[[类型:参数]]标注的内容[[/]]
```

例如 `[[c:jose_arcadio]]何塞·阿尔卡蒂奥·布恩迪亚[[/]]` 标记一个角色，`[[r:spouse]]丈夫[[/]]` 标记一段关系，`[[p:sensor_01]]距离传感器[[/]]` 标记一个部件。

它遵循四条设计原则：

1. **降级可读**——即使完全去掉标注，文本本身依然完整可读，和 Markdown 一样天然；
2. **机器可解析**——每个标注都有明确的语义类型和参数，程序可以零歧义地提取；
3. **垂类可扩展**——不同领域定义自己的标注集，但共享同一套底层语法。这也是"流形"这个名字的由来：数学中的流形，每个局部有自己的坐标系，整体却连成一体；
4. **一次处理，终身使用**——LLM 在预处理阶段完成标注，运行时零 API 调用，内容可以被无限次渲染、交互、传播。

在标注文本之上，是通用的 **Manifold Renderer**：文本层正常渲染内容；交互层识别标注并绑定行为——悬浮出迷你卡、点击出详情面板、拖拽展开关系图、选中直接问 AI；视图层支持在同一数据上切换阅读视图、图谱视图、时间线视图、重建视图。文本、交互、视图三层解耦，意味着同一套引擎可以驱动完全不同的产品形态。

## 三、产品矩阵：一个引擎，六个垂类

Manifold 不是一个单品，而是一个 Solution：同一套标注语法和渲染引擎，向下分拆出六个垂类产品。

**P.01 读书 · AI 阅读伴侣（已上线）**。读长篇和复杂叙事时，替你记住"谁是谁"。以《百年孤独》为例——布恩迪亚家族七代人，十几个同名的何塞·阿尔卡蒂奥和奥雷里亚诺，读者读到一半必然崩溃。Manifold 在预处理阶段通读全书，把每个角色、每段关系、每个关键事件标注进正文：阅读时名字高亮，点一下弹出角色卡（定妆头像、一句话简介、已读范围内的关系简图），侧滑展开力导向关系图，还能选中原文直接问 AI。防剧透是硬设计：预处理数据分 identity（安全身份）、full_description（含命运结局）、key_events（带章节号）三层，展示层严格按阅读进度过滤——AI 知道全书，但只告诉你读到的地方。我们已预处理《百年孤独》《红楼梦》《水浒传》《霍乱时期的爱情》等多部经典。

**P.02 拆解 · 拆解打造（已上线）**。AI 的输出是线性的，但系统理解是结构化的——部件如何连接、信号怎么流动、能量怎么传递，在文字里全是隐式的。输入一个名字或上传一张照片，Manifold 把对象一层层拆开：第一层展示核心子单元及关系连线，点击任意单元展开下一层；结构、信号、能量、因果四种视图自由切换。看懂之后点"重建它"，进入重建模式：零件清单、连接关系、所需工具与成本、分阶段步骤、每步验收标准、常见错误排查、安全提示——从"理解一个东西"到"真的把它做出来"。

**P.03–P.06 未来垂类（路线图）**。游戏攻略模式（BOSS 技能时间线、决策树、装备掉落网，路线图第一优先级）；历史时间线模式（因果链力导向图、势力消长图，把时间这个维度引入标注体系）；菜谱烹饪模式（步骤依赖树、食材替代网、失败排查路径）；知识学习模式（概念前置依赖网络，把"学不会"定位成具体的前置缺口）。每个垂类都有自己的标注集，但全部运行在同一个 Manifold 引擎上——文学和系统两个南辕北辙的领域已经跑通，就是对这种可扩展性最有力的证明。

## 四、区块链内容层：让好内容成为资产

Manifold 定义的不只是"更好看的输出"，而是内容的语义化新标准。新标准需要新基建，我们选择基于 **Injective 区块链** 构建内容层：

- **存证**：预处理生成的结构化内容包（含标注文本、知识图谱、元数据）计算哈希上链，内容指纹 + 创作者地址 + 时间戳，上链即确权，单笔 Gas 约 0.0003 美元、0.65 秒确认；
- **分发**：内容包存储于 IPFS / Arweave，链上哈希指向存储地址，可验证、永久可访问，不依赖任何平台的服务器；
- **流转**：内容包可铸造为 NFT 交易，创作者获得版税，每次转售自动分成，没有中间商；
- **发现**：按垂类、热度、创作者索引链上内容——你的《百年孤独》人物图谱、别人做的《黑神话：悟空》BOSS 攻略包，都能在同一个标准下被发现、使用、二次创作。

同一标准 + 链上确权，让 UGC 从散落在各平台的孤岛，变成可积累、可组合、可流通的内容生态。

## 五、差异化：我们不在任何既有赛道里

对比 Markdown：Manifold = Markdown + 语义标注，且降级可读；对比 Mermaid / DiagramGPT：它们生成独立的图解，Manifold 把标注嵌在文本里，图文一体；对比 Readwise / 微信读书：它们做笔记和社交，Manifold 在阅读过程中实时辅助；对比 ChatPDF：它做文档问答，Manifold 做深度角色追踪、关系图和防剧透；对比 iFixit：它给维修教程，Manifold 给系统理解、多视图探索和重建验证。
